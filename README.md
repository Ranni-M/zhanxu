# 展序 ZHANXU

**把毕业设计作为一个完整项目展示。** 上传图片、视频、论文和项目文件，按模块组织创作过程，生成独立公开页，并导出封面或多页图文包。

这是可运行的全栈应用，适合个人毕业设计、作品集，以及单台服务器上的小规模共享使用。界面采用 taste-skill，交互细节应用 Emil 的设计工程规范。

## 功能

- 邮箱密码注册、登录、退出、修改密码，服务端会话。
- 每个账号独立的项目工作台；保存、重新打开、删除与未保存内容恢复。
- 项目介绍、创作者、职责、工具、制作过程、在线体验及源码链接。
- 最多8个自由内容模块，支持调整顺序和关联图片。
- 图片、完整PDF、MP4/WebM视频与ZIP项目包上传。
- PDF在浏览器解析前6页预览，尝试提取摘要；完整文件始终保留。
- 独立公开项目页；私有草稿与公开快照分离；附件逐个控制公开；可更新或撤回。
- 已发布作品发现、分类搜索与账号收藏。
- 三种封面版式；后台导出1600px宽PNG封面或自动分页的PNG图文ZIP。
- 主题切换、手机布局、键盘操作和减少动态效果支持。

**上传ZIP不会运行整个项目。** 软件毕设请填写部署后的体验地址和代码仓库；动画、游戏、装置等可上传演示视频。展示页负责完整呈现成果，封面只是入口。

## 快速开始

要求 **Node.js 24+**。不需要外部数据库、云存储账号或AI密钥。

```sh
npm ci
npm run dev
```

浏览器打开 http://127.0.0.1:5173 。前端5173端口代理后端3001端口。注册自己的账号后即可创建项目。

运行生产构建：

```sh
npm run build
npm start
```

打开 http://127.0.0.1:3001 。该端口同时提供网页和API。

首次启动自动创建 data/zhanxu.sqlite 和 data/files/。这些文件已被Git忽略；上传素材与账号数据不会进入代码仓库。

## 配置

复制 .env.example 为 .env，再按需要修改。npm start 自动读取 .env；开发命令默认使用本机配置，也可以通过进程环境变量设置。

| 配置                | 默认值                | 说明                                        |
| ------------------- | --------------------- | ------------------------------------------- |
| PORT                | 3001                  | API/生产网站端口                            |
| HOST                | 127.0.0.1             | Docker内为0.0.0.0                           |
| DATA_DIR            | ./data                | SQLite与文件持久化目录                      |
| PUBLIC_ORIGIN       | 本机开发地址          | 生产必须设置，例如https://portfolio.example |
| COOKIE_SECURE       | 根据PUBLIC_ORIGIN推断 | HTTPS生产站点应为true                       |
| TRUST_PROXY         | 不信任代理            | 仅在确实只有一层可信反向代理时设置1         |
| MAX_USER_STORAGE_MB | 500                   | 每个账号上传素材的空间上限                  |
| ALLOW_REGISTRATION  | true                  | false时关闭新账号注册                       |


## 当前边界

- 单实例Node进程、SQLite与本地文件系统；不要把同一SQLite卷作为多台应用服务器的共享数据库。
- 邮箱是登录标识，当前没有邮件验证码、找回密码邮件或第三方登录。
- 没有AI语义摘要、OCR、视频转码、在线执行ZIP、团队协作或付费系统。
- 视频能否播放取决于文件编码及浏览器；推荐H.264/AAC MP4或WebM。
- 公开站点运营所需的内容审核、滥用处理和可观测性可以在此基础上扩展。
- 当前网站只运行在本机；要让其他人远程访问，需要按部署文档部署到有域名/公网地址的服务器。
