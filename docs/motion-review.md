# Emil设计工程审查与修改

采用 emil-design-eng 与 mobile-native。以下修改已经实现，并非只安装技能。

| Before                                      | After                                        | Why                            |
| ------------------------------------------- | -------------------------------------------- | ------------------------------ |
| 全局按压改写transform，倾斜纸张可能瞬间摆正 | scale长属性缩到0.98，140ms反馈，保留已有旋转 | 保留空间连续性，按下立即响应   |
| 卡片悬停350ms、纸张400ms                    | 200-240ms自定义ease-out                      | 高频交互不应等待长动画         |
| 每次筛选都重新播放列表进场                  | 列表切换即时更新                             | 不延迟反复操作                 |
| 弹窗只有进入动画                            | 230ms进入、140ms退出                         | 退出更利落                     |
| 键盘操作也会播放过渡                        | 键盘输入模式关闭动画，指针操作恢复           | 键盘操作需要即时反馈           |
| 手机搜索框12px                              | 粗指针设备输入框至少16px                     | 避免iOS聚焦输入时自动放大      |
| 浏览器状态栏固定浅色                        | 主题切换同步theme-color                      | 深色模式不出现突兀浅色浏览器栏 |
| 控件依赖默认点击行为                        | manipulation触摸行为、控件禁止文字选择       | 减少触摸延迟及长按误选         |
| 内容滚到边缘继续带动底层页面                | 弹窗与画布contain overscroll                 | 防止滚动穿透                   |

已有正确项：hover样式按设备能力开启，所有移动遵守prefers-reduced-motion，模态框焦点与Escape由Radix处理，使用动态视口单位，导出栏预留底部安全区域。

验证范围：真实Chromium浏览器桌面测试与手机尺寸/触摸模拟；没有连接实体手机，iOS键盘、安全区域与触摸手感仍需手机验证。
