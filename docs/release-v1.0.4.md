# 展序 v1.0.4

毕业设计完整项目展示平台，包含账号、项目与素材管理、模块化作品页、公开发布及撤回、封面与作品集导出。

本版是一轮「去重」修正：示例作品与模板展示之前看起来像同一个作品的九种换色，现在每套模板都配一个真正不同的示例作品。数据结构不变，可直接覆盖升级。

- 展示模板页与首页模板区改成「一套模板配一个示例作品」（新增 `sampleForTemplate()`）：九个卡片是九个作品，不再是同一个作品换九套配色。
- 示例作品补齐五张各不相同的图片（工作台、铅字纸样、夜灯、旧相机、黑白剪影），九件示例各有一张图，发现区不再出现同一张照片反复出现。图片来源见 docs/assets.md。
- 首页模板区的九个卡片与展示模板页共用同一份预览图，发现区、模板页、首页三处看到的示例互不重复。
- 测试：浏览器检查新增「展示模板页：九套模板配九个不同示例」（断言九张卡片、九个不同预览），共 23 项；单元测试 46 项。
- 截图更新：docs/screenshots/home.png、home-features.png、home-discover.png，新增 templates.png（展示模板页）。

运行：Node.js 24+，执行 npm ci、npm run build、npm start，访问本机 3001 端口。网站与 API 部署见 docs/deployment.md。

源码不包含实际用户数据库、上传文件、环境密钥和测试产物。
