# 展序 v1.0.2

毕业设计完整项目展示平台，包含账号、项目与素材管理、模块化作品页、公开发布及撤回、封面与作品集导出。

本版集中补齐「首页功能表达」与三处既有问题，不改动数据结构，可直接覆盖升级：

- 首页新增功能区：零填写导入、九套主题与六种排版、改动前后对比、作品集 PDF、展台二维码、素材一次收齐，每格都用真实组件演示而不是示意图。
- 首页发现区可选项更完整：分类标签显示作品数量，排序支持推荐顺序、最新发布、名称排序与收藏优先，并显示当前结果与筛选状态。
- 进场动效统一走 `.reveal` 与 `prefers-reduced-motion`，关闭动态效果时直接呈现内容；同时修掉手机端旋转海报造成的横向可拖动。
- 修复模板预览图重样、空草稿混进「我的作品」、首页模板卡片说明重复三处问题（v1.0.1 交付物内已含修复）。

运行：Node.js 24+，执行 npm ci、npm run build、npm start，访问本机 3001 端口。网站与 API 部署见 docs/deployment.md。

源码不包含实际用户数据库、上传文件、环境密钥和测试产物。
