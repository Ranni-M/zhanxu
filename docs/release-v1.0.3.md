# 展序 v1.0.3

毕业设计完整项目展示平台，包含账号、项目与素材管理、模块化作品页、公开发布及撤回、封面与作品集导出。

本版加了三件事，数据结构不变，可直接覆盖升级：

- 发现区铺满九套模板：示例作品从 4 个补到 9 个，九种版式各一件。列表会把「真实公开项目 + 还没出现过的模板示例」拼在一起，示例卡片带「示例」标记、不显示收藏按钮，点进去是公开项目页的效果演示。
- 新增「单文件网页版作品集」导出：把整个项目（封面、展签、正文分节、图集、对比、链接、二维码）排成一个 .html，图片内嵌为 data URL，双击就能离线打开，也能直接上传到任意静态空间。带打印样式，浏览器里 Ctrl+P 就是一份干净稿件。游客与登录用户都可用，纯浏览器计算，不占服务端导出队列。
- 导航与页面抬头加强：发现作品/展示模板/我的作品三个入口字号、间距与选中下划线加大，「发现作品」「展示模板」「我的作品」等页面标题的字号与行距同步提升，层级更清楚。

运行：Node.js 24+，执行 npm ci、npm run build、npm start，访问本机 3001 端口。网站与 API 部署见 docs/deployment.md。

源码不包含实际用户数据库、上传文件、环境密钥和测试产物。
