# 展序 v1.0.5

毕业设计完整项目展示平台，包含账号、项目与素材管理、模块化作品页、公开发布及撤回、封面与作品集导出。

本版是一轮纯前端样式修正，专治手机上的两个毛病：展示模板区和文案叠在一起、页面能左右拖动。数据结构与 API 不变，可直接覆盖升级。

- 修「模板区和文案重叠」：窄屏（≤980px）模板区改成单列后，左侧文案仍是 `position: sticky`，会被钉在视口顶部，下面正常滚动的模板卡从它底下穿过去。现在单列时文案回到静态定位，桌面宽屏的吸顶效果原样保留。
- 修「页面横向溢出」：360/375 宽的手机上页面会宽出 72px，能左右拖。原因是 hero 区网格项按最小内容宽度撑开——标题是不换行的，两个按钮文案也不换行。现在窄屏允许标题换行（仍是两行，`text-wrap: balance`）、按钮可换行、hero 子项 `min-width: 0`。
- 修「二维码卡片撑宽」：展台二维码卡片里的作品地址是 `nowrap`，窄屏会把卡片顶出视口。现在单列时文案按卡片宽度收缩，地址过长用省略号截断。
- 测试：浏览器检查新增两项回归——手机端断言模板区文案必须是静态定位且滚动时与模板卡零重合；另开一个**普通**窄窗口在 360px 下检查首页与展示模板页无横向溢出（原先的 390px 检查用了 `isMobile` 模拟，布局视口跟着一起变宽，所以漏掉了这个 bug）。共 24 项；单元测试 46 项。
- 覆盖 320 / 360 / 375 / 390 / 414 五档宽度，首页、展示模板、我的作品、账号、公开作品页均无横向溢出。

运行：Node.js 24+，执行 npm ci、npm run build、npm start，访问本机 3001 端口。网站与 API 部署见 docs/deployment.md。

源码不包含实际用户数据库、上传文件、环境密钥和测试产物。
